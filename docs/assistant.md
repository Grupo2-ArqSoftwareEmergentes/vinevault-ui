# Floating inventory assistant

- `AppComponent` mounts one `AssistantWidgetComponent` across Overview, Devices, Alerts, Cavas, Inventory (including editor routes), Spaces and Subscription. Navigating between these routes preserves the widget/thread; public/onboarding routes unmount it. The former embedded inventory analysis component is no longer mounted.
- `AssistantService` POSTs to `API_CONFIG.endpoints.assistantChat` (`/api/v1/assistant/chat`): `space_id`, optional `cellar_id`, `mode` (`CHAT` or `SOMMELIER_ANALYSIS`), `message` and `history`. No cellar means the whole space, not the first cellar implicitly. The Core response uses `reply`, `mode`, `context_summary`.
- Core limits both the message and each history entry to 2000 characters, with at most 10 history entries (`role: user | assistant`, `content`). Only completed user/assistant pairs enter history, excluding the current prompt and failed turns. Replies are displayed in full but bounded when sent back as history.
- Chat sends only on explicit submit; Sommelier submits a predefined diagnostic request. Neither writes inventory nor refreshes quotas. Pending requests block duplicate submission but not closing the panel, navigation or drafting the next question. There are no automatic retries.
- Conversation and draft are memory-only, never localStorage. Space/cellar or authorization changes clear the thread, cancel pending requests and reject stale responses. Same-context metadata refreshes do not clear it; logout resets context and public routing destroys the widget.
- Assistant/autocomplete 403s indicate optional analysis permission, not revoked space membership: `ErrorInterceptor` passes them through without clearing selection/session. The widget gives local feedback for 403/422/network/server errors while preserving previous successful turns. 401 still follows normal logout handling.
- Responses render with Angular text interpolation and `white-space: pre-wrap`, not trusted HTML or unsanitized Markdown. The modeless panel supports Escape, focus return and a live transcript; overlay z-index stays below Material dialogs.
